# Data Policy

`synthetic/sales_training.csv` is deterministically generated by `scripts/generate_synthetic_data.py`. It contains no real people, real customer identifiers or company data.

Do not replace it with production data in this public repository. Production assessment should reference restricted, approved evidence by durable ID and use a separately governed environment.

The synthetic label intentionally encodes simple learnable relationships so tests are reproducible. It has no business, causal or fairness validity.
