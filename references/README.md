## Source-use note

- EBIOS RM provides the scenario-analysis method.
- NIST RMF provides the security/privacy lifecycle.
- SP 800-53 provides selected outcome-oriented controls; control text/titles should be checked against the official current release before formal use.
- AI RMF provides AI trustworthiness/governance outcomes.
- MITRE ATLAS and draft OWASP ML Top 10 inform threat research and technical scenarios; they do not determine risk ratings automatically.
