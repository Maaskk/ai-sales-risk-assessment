# EBIOS Tools

- `ANSSI-EBIOS-RM-official-template.xlsx` is an untouched download of the official ANSSI workshop template from <https://messervices.cyber.gouv.fr/documents-guides/EBIOS_RM_Ateliers_modele.xlsx>, retrieved August 25, 2026.
- `ai-sales-ebios-working-file.xlsx` is the populated, formula-driven reference workbook for this project. It covers all five workshops, the provisional risk register, treatment plan and selected control mapping.

The official workbook was kept untouched because its embedded chart includes an axis value that the automated spreadsheet engine could not parse safely. Use the project workbook for this assessment and the ANSSI file as an authoritative layout/reference aid.

The ANSSI online EBIOS RM service can also be accessed from <https://messervices.cyber.gouv.fr/ressources/ebios.html>. Account access and workshop decisions remain user-owned.
