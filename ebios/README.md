# EBIOS Risk Manager Analysis

The five folders form one iterative analysis. All company-specific content is provisional and must be reviewed in workshops.

| Workshop | Main output in this repository |
|---|---|
| 1 | Scope, business values, supporting assets, feared events, baseline |
| 2 | Risk-source/objective pairs and relevance |
| 3 | Ecosystem map and strategic scenarios |
| 4 | Technical operational paths, plausibility and threat-intelligence mapping |
| 5 | Treatment, residual risk, owners and roadmap |

Risk calculation for this working draft: `inherent = severity × likelihood`, using the criteria in `risk-register/method.md`. EBIOS itself should be facilitated and contextual; this formula is a repository convention, not an ANSSI mandate.
