# NIST AI RMF 1.0 Profile

This profile applies NIST AI RMF 1.0 to the predictive recommendation concept. It is outcome-based and voluntary, not a certification checklist. NIST states that AI RMF 1.0 is under revision as of August 25, 2026; re-baseline when the revision is finalized.

| Function | Purpose in this assessment | Artifact |
|---|---|---|
| GOVERN | Accountability, policy, culture and lifecycle oversight | `govern.md` |
| MAP | Intended use, context, people, impacts, data/model dependencies | `map.md` |
| MEASURE | Test, evaluate, verify and validate trustworthy characteristics | `measure.md` |
| MANAGE | Prioritize, treat, monitor, respond and improve | `manage.md` |

Statuses refer to the synthetic lab and documentation only. Production status is unknown unless separately evidenced.
